# E04: Python for Data Science II: Loops, Conditions and Functions
Video: https://youtu.be/MN39wEHRl0o

Every file comes as a `.py` script (cells marked with `# %%`) and as a Jupyter notebook (`.ipynb`) with the real outputs. Python 3.13. No data file needed: the scores are typed in.

- `e03_solution.py` / `.ipynb`: solution of the E03 exercise (a dictionary about yourself, average study hours rounded to 1 decimal)
- `compare.py` / `.ipynb`: comparisons, `and` / `or`, and the `bool` type
- `if_else.py` / `.ipynb`: `if` / `else`, pass or fail
- `elif_grades.py` / `.ipynb`: `elif` letter grades, and what goes wrong when the checks are in the wrong order
- `for_list.py` / `.ipynb`: a `for` loop over a list of scores
- `for_items.py` / `.ipynb`: looping over a dictionary with `.items()`
- `range_demo.py` / `.ipynb`: `range()` with one, two and three numbers
- `total.py` / `.ipynb`: the accumulator pattern, a total and a count
- `while_demo.py` / `.ipynb`: a `while` loop (weeks to reach 20 study hours)
- `break_continue.py` / `.ipynb`: skipping a missing score with `continue`, stopping at the first fail with `break`
- `comprehension.py` / `.ipynb`: list comprehensions, with and without a filter
- `def_average.py` / `.ipynb`: your first function, `average(values)`
- `defaults.py` / `.ipynb`: a default argument (`pass_mark=50`), a docstring and `help()`
- `tests.py` / `.ipynb`: testing functions with `assert`
- `indent_error.py`: run it to see a real `IndentationError`
- `forgot_return.py` / `.ipynb`: a function that forgets `return` and gives `None`
- `mini.py` / `.ipynb`: the mini analysis of the first 10 students of `students.csv`: `count_passes()` and `top_student()`
